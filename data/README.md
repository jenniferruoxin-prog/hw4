# Put the data pack here

This folder is intentionally empty in the repo. The course database and product photos are **not** committed (see `.gitignore`).

Unzip the course `data.zip` into the `hw4/` folder (the zip already contains `data/`). You should end up with:

```
data/campus_customs.db     # SQLite: catalogue, inventory, users, chat_messages
data/products/*.jpg        # 102 product photos
```

The database is test data for a class project. Its accounts are course test accounts, not real customers. See the main [README](../README.md) for how to run the site.
